# 🎬 MovieExplorer

A responsive movie browsing app built with React, React Router, and the TVMaze API — practice project for the Apollo Level2 Web Dev Foundation Program.

## Features
- Home page with hero section
- Movie listing page with search (TVMaze API)
- Responsive movie grid with poster, title, year, and rating
- Movie details modal with overview, genres, and release info

## Tech Stack
- React (Vite)
- React Router
- TVMaze API

## Running locally
\`\`\`
npm install
npm run dev
